LINUX LOG SOURCES
=================

Environment:
- Kali Linux
- Virtual Machine
- User: kali

Primary logging mechanism:
- systemd journal

Relevant sources identified:

1. journal/
   General system and service logs available through journalctl.

2. wtmp
   Login/session history used by the `last` command.

3. wtmp.db
   Additional login/session database present on the system.

4. btmp
   Failed login database.
   The file was present but had 0 bytes during the investigation.

5. boot.log
   System boot-related information.

6. Xorg.0.log
   Xorg graphical server logs.

7. lightdm/
   Logs associated with the LightDM display manager.

8. Service-specific logs
   Additional logs generated by individual services.

Important observation:
- /var/log/auth.log was not present on the system.
- Authentication and service events were therefore primarily investigated
  through the systemd journal using journalctl.
