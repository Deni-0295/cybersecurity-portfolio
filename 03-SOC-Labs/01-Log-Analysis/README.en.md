# Linux Log Analysis

## Overview

This lab focuses on the analysis of Linux system logs from a Kali Linux virtual machine.

The objective is to practice identifying authentication events, privileged activity, scheduled tasks, SSH activity, and system errors using Linux logging mechanisms and command-line tools.

The investigation follows a SOC-oriented approach by collecting evidence, classifying events, and distinguishing normal system activity from events that may require further investigation.

---

## Objectives

* Identify relevant Linux log sources.
* Analyze authentication-related events.
* Investigate SSH activity.
* Review privileged activity performed through `sudo`.
* Identify scheduled tasks executed by CRON.
* Review system errors reported by `systemd` and other services.
* Correlate events from different log sources.
* Document findings using reproducible evidence.

### 5. System Errors

## Key Findings

The investigation identified several authentication-related events associated with the local graphical environment.

A LightDM authentication failure was observed where the user was reported as unknown and no remote host was recorded.

An Xfce screensaver authentication failure was also observed for the local `kali` account.

No SSH authentication events were identified in the reviewed period.

Several CRON sessions were observed running as `root`, consistent with scheduled system activity.

System errors related to virtualization and desktop components were also identified.

These observations were documented separately to avoid treating normal system activity as confirmed malicious activity.

## Investigation Methodology

The investigation followed these steps:

1. Identify available log sources.
2. Review authentication-related events.
3. Search specifically for SSH authentication activity.
4. Review privileged activity.
5. Review scheduled CRON sessions.
6. Identify system errors.
7. Correlate events by timestamp and service.
8. Classify events based on the available evidence.
9. Document findings and limitations.

---

## Result

This lab demonstrates the basic workflow of a SOC analyst when investigating Linux logs:

**Collect → Filter → Correlate → Classify → Document**

The evidence collected during this lab can be used as a foundation for more advanced investigations involving brute-force detection, SIEM platforms, detection rules, and incident response.
