SUDO ACTIVITY
=============

Investigation objective:
Review privileged activity performed through sudo and identify
commands executed by the local user during the investigation.

Command used:

sudo journalctl -t sudo --since "7 days ago" --no-pager

Observed activity:

- sudo sessions were generated by the user `kali`.
- The activity corresponded primarily to investigation commands.
- sudo session open and close events were observed.
- No suspicious command was identified from the reviewed activity.

Examples of investigation commands executed with sudo included
journalctl queries for:

- SSH activity
- sudo activity
- authentication events
- system errors
- service status

Interpretation:

The observed sudo activity is consistent with administrative
and investigative activity performed during the Linux log-analysis
lab.

Important limitation:

The presence of sudo activity alone does not indicate malicious
privilege escalation.
